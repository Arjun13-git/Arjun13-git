I'm a Computer Science Engineering student at **Sahyadri College of Engineering & Management, Mangalore**, working somewhere between AI/ML, software engineering and research.

I like taking ideas that sound slightly unreasonable — *can a 4-qubit circuit classify galaxies? can a Mamba model read an ECG?* — and building them anyway, properly evaluated, with an API and a UI on top. Most of my work lands in machine learning, backend systems, computer vision, LLM agents, quantum machine learning and AI security. A lot of it started at hackathons.

<img src="https://img.shields.io/badge/status-research_prototype-0E7490?style=flat-square" alt="Status: research prototype" />

Entity resolution / record linkage pipeline for the Amazon ML Challenge 2026: match each business record to every record in two other sources that describes the same real-world business.

**Why it's interesting:** blocking cuts trillions of possible pairs down to a few hundred candidates per record before an XGBoost matcher scores them.

<sub>`Python` `XGBoost` `Pandas` `scikit-learn` `RapidFuzz`</sub>

Classical deep learning vs. hybrid quantum-classical models for exoplanet transit detection in NASA Kepler and TESS light curves.
